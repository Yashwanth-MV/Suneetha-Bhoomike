# Suneetha Bhoomike — School of Music, Mysuru

The official website for **Suneetha Bhoomike**, a premier school of music in Mysuru founded by **Bhoomika Koundinya**. Offering classes in Carnatic vocal, Sugama Sangeetha, devotional music, and instruments including Piano, Guitar, Violin, and Drums.

## Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile
- **Smooth Animations** — Powered by Framer Motion for fluid transitions
- **Online Registration** — Integrated registration form for new students
- **Course Catalog** — Browse available programs and class schedules
- **Community Section** — Meet the instructors and community leaders
- **SEO Optimized** — Full metadata, Open Graph, and structured data

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Smooth Scroll:** Lenis

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

## Deployment

Deploy on any platform that supports Next.js:

- **Vercel** — Recommended for seamless Next.js deployment
